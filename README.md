## Overview

**Hompai API** serves as the dedicated backend repository for the **[HompaiMobile](https://github.com/jomudev/HompaiMobile)** ecosystem, designed to handle RESTful endpoints, pantry/article synchronization, reminders persistence, and structured database queries.

---

## Planned & Companion Capabilities

- **Companion Client:** Integrated with [`HompaiMobile`](https://github.com/jomudev/HompaiMobile) (`src/apis/Reminders.js`, `modules/AIapi.js`, `modules/Axion.js`).
- **Core Responsibilities:**
  - User authentication token verification & profile persistence.
  - CRUD endpoints for household pantry items, batches, and categories.
  - Scheduled reminder triggers supporting Firebase Cloud Messaging (FCM) push notifications.

> **Repository Status:** Currently houses the base repository scaffold (`LICENSE`, `.gitignore`, and architectural spec) while mobile client development progressed in [`HompaiMobile`](https://github.com/jomudev/HompaiMobile).
